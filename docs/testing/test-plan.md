# 行为测试

测试保护产品行为，不证明文件布局或报告体系存在。实际执行结果放 PR，不在本文回填逐项状态。

## 模型与数据库

- Project 成员授权，Course 可选的科研 Work；课程关闭不影响独立项目。
- 申请、审批、租约、取消与回收状态；重复和乱序事件、进程恢复、旧代次条件更新。
- 显式事务中的业务写入、防重和 Outbox；失败不提交部分状态。
- 真实 PostgreSQL 空库迁移与约束；不通过静态 SQL 文本匹配替代数据库行为。
- GPU 目录/模式和容量约束；费用区间、费率版本、重复入账、调整与未知计量。

## 服务边界

- 服务 JWT 的签名、issuer、audience、期限、调用权限及密钥轮换；用户会话和范围独立校验。
- 未授权、越权、撤销、过期、身份/数据库不可用必须拒绝访问。
- 冻结提交、实时 Probe 目标变化、基础设施失败与学生失败的区别、LLM 不写确定性成绩。
- 受限进程和 Job 的超时、输出上限、取消、终态及资源清理。

## 页面与部署

真实业务后端的 Playwright 旅程覆盖独立 Work、教师发布、学生运行/提交/反馈、资源审批与费用。刷新、断线和重复点击不能新增资源或账单。组件测试可以使用响应场景数据；外部执行与模型可以 Mock，不维护前端模拟业务状态机。

Ansible/Helm 的本地测试检查渲染后配置、权限、网络、清理范围和无 Secret 输出。真实 KubeVirt、GPU 和集群流量需对应环境另行验证；本轮不连接共享集群。

运行受影响包和页面测试，公共契约/权限/持久化/费用扩大验证，最后进行整体检查。不要固定 sleep 等待业务，使用状态、事件或进程终态。日志和临时测试产物用于故障排查，不成为运行时准入条件。
