# ADR 0015：v3 项目、Work 与资源平台

状态：用户批准的实施方向；实际实现与测试见 Issue #180 的 PR。

## 决定

保留六个独立业务服务。Project 为基本归属，Course 为可选教学关联；Work、实验与一次性任务复用真实执行设施，保留各领域生命周期与规则。

Environment 唯一管理环境 Kubernetes 对象；Resource 管分配授权、审批、租约和费用。Evaluation 恢复完整统一评测，通过批准的脚本/镜像包扩展，LLM 不影响确定性成绩。Agent 在隔离范围构建、验证配置和镜像，私人 Work 配置遵守预授权和重启影响提示。

服务身份采用 Keycloak 服务账户与 JWT，使用服务端 TLS，独立执行用户范围授权。删除固定身份与假 mTLS 包装；不推导为删除 NATS 或 SSH 的安全机制。

GPU 目录区分独占、容器时间片和 VM vGPU。接入设备插件与 KubeVirt mdev，不实现 GPU 调度器。模式不满足时明确失败，不回退到普通容器或 Mock。MIG 不属于本次范围。

Resource 内维护显式单位和版本化费率、固定精度费用、区间用量与管理员调整。计算从可使用起计，异常清理进入待核实，存储独立核算。没有费率显示未配置；不默认预算强停或真实支付。

## 简化与代价

删除无消费者抽象、前端模拟业务后端、假成功、旧日期冻结及专用证明报告体系。保留真实输入稳定性、调用身份、授权、幂等、取消、代次、资源释放和诊断日志。

允许共享 PostgreSQL 的有限跨 Schema 事务，接受明确数据库耦合，不宣称每个服务可零成本迁到独立数据库。不新增通用事务引擎或万能实体。

本次整体升级所有仓库内消费者，不保留旧 API 包装。旧课程冻结、freeze-only、Resource disabled、GPU Mock、固定拓扑发布证明和无条件禁止跨 Schema 事务的历史决定被本 ADR 替代；其他仍有效的行为约束继续保留。

## 验证边界

本轮只实施代码与本地验证，不操作共享集群、不清空远端数据。真实 GPU/KubeVirt 能力需对应硬件验证，外部执行边界 Mock 仅用于本地行为测试。核心评审由 A/B、前端由 C、测试与部署验证由 D 负责；作者不自行批准、合并或发布。
