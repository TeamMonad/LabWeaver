# Acceptance Criteria

## Interpretation

Requirement IDs are stable references for implementation issues, tests,
reports, and release evidence. A target evidence level describes the minimum
proof needed before an item can be accepted; it does not upgrade current
evidence. A future owning contract must define its exact diagnostic code before
runtime implementation. Existing `LW_EVAL_*` diagnostics remain authoritative
only where already defined by the EvaluationSpec contract.

## Current P0 release-gate cross-check

The P0 rows above cannot be marked complete until their target evidence is
produced by the same build/deployment identity. The current repository has no
E3/E4 evidence for real KubeVirt, Access, Resource, Evaluation runtime,
Ansible, or Playwright paths. This document adds no Release Gate pass and does
not change any capability state to `done`.
